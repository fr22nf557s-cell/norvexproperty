# Norvex Property

The website for norvexproperty.com. One page: a scroll-driven film of the
flagship listing with six chapters, then current instructions, mortgage and
bridging calculators, the survey comparison and an enquiry form.

Hosted on GitHub Pages from the `main` branch. The domain is set by `CNAME`.
Source of the wider project (design brief, hosted build, encoder scripts):
